## 问题：寄存器都有哪些

很显然寄存器这种高速访问器是不可能给你放多的 ~~因为你没钱~~

通用寄存器：

RAX, RBX, RCX, RDX, RDI, RSI, RBP, RSP 和 R8–R15

为什么是 R8？很显然，RAX - RBP 为 R0 - R7。

顾名思义，“通用”就是任何时候都能用的寄存器，所以在 C 语言编译而成的汇编语言就有很多它们的影子。

还有一部分系统寄存器，但是你用不到，那是操作系统考虑的事了。

## 问题：寄存器的常用方法

| 寄存器 | 描述 |
| --- | --- |
| eax | 操作数的运算、结果 |
| ebx | 指向 DS 段中的数据的指针 |
| ecx | 字符串操作或者循环计数器 |
| edx | 输入输出指针 |
| esi | 指向 DS 寄存器所指示的段中某个数据的指针，字符串操作中的复制源 |
| edi | 指向 ES 寄存器所指示的段中某个数据的指针，字符串操作中的目的 |
| esp | SP 寄存器 |
| ebp | 指向栈上数据的指针 |
| rdi | 传递第一个参数 |
| rsi | 传递第二个参数 |
| rdx | 传递第三个参数或者第二个返回值 |
| rcx | 传递第四个参数 |
| r8 | 传递第五个参数 |
| r9 | 传递第六个参数 |
| rax | 临时寄存器或者第一个返回值 |
| rsp | sp 寄存器 |
| rbp | 栈帧寄存器 |
